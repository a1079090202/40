# 球馆预订计费系统（Remix + SQLite + TypeScript）

面向 4 块羽毛球场 + 2 个篮球半场的球馆：场地半小时粒度挂日历，教练班课周期批量占场，
散客先到先得、撞班课必拦并给替代，会员卡（按场地类型的次卡 / 按金额的储值卡）
下单冻结、核销扣减、2 小时内取消与爽约不退，月违约 3 次限订一周，月底出三张表。

- 金额一律按 **分（整数）** 存储；时段一律本地时间、**半小时粒度**，slot key 形如 `2026-09-22 19:00`
- 全栈 TypeScript；服务端模块零框架依赖，可直接被 vitest/CLI 调用

## 运行

```bash
npm install
npm run seed       # 写入样例数据（6 场地/3 教练/4 班课/10 会员三类卡/两周日历）
npm run dev        # 开发：http://localhost:3000
# 或
npm run build && npm start
npm test           # 34 个测试（4 模块单测 + 五步验收端到端）
npm run typecheck
```

数据库默认 `data/arena.db`，可用 `DATABASE_PATH` 覆盖。

## 四个独立模块（app/server/）

| 模块 | 文件 | 职责 |
| --- | --- | --- |
| 班课批量占场 | `courses.ts` | 周期展开 N 周；命中节假日/整段请假按配置 **顺延**（之后第一个空档）或 **补课**（名义日 leave，周期结束后同星期补）；节假日表变动后 `reexpandAll` 全班课重排 |
| 冲突与替代推荐 | `bookings.ts` + `availability.ts` | 班课/散客占用统一查询，半开区间重叠检测；先到先得（事务内复查防并发穿透）；替代三级：①同日同时段其他同类型场 ②同日相邻平移（优先原场）③未来 14 天同时段 |
| 卡额度冻结扣减 | `wallet.ts` | 次卡冻格数（一次一格）、储值卡冻金额（场租+晚场灯光预估）；`card_holds` 记录冻结生命周期，`card_txns` 全量留痕；核销转真实扣减，>2h 取消释放，≤2h 取消/爽约不退 |
| 违约规则 | `violations.ts` | 爽约扫表：开始 +30 分钟未核销 → 扣没冻结 + `no_show` + 记违约；自然月 3 次 → 第 3 次起限订 7 天，下单前 `assertNotBanned` |

辅助：`time.ts`（半小时粒度）、`pricing.ts`（场租/灯光，晚 18:00 起开灯）、
`config.ts`（单价与阈值）、`reports.ts`（三张月表）、`catalog.ts`（场地/教练/会员/节假日）。

### 计费口径（config.ts 可改）

- 场租：羽毛球 15 元、篮球半场 30 元 / 半小时；灯光（18:00 起每格）：羽毛球 2 元、篮球 5 元
- 次卡核销扣格数，灯光费现收计场馆收入；储值卡核销扣场租+灯光
- 爽约/迟到取消扣没的冻结计场馆收入（灯光未实际产生，不单独计灯光收入）

## 页面

- `/calendar` 场地日历：6 场 × 半小时格分色（蓝=班课/黄=补课/绿=散客/红=爽约），点空格下单；
  被拦时错误框内直接列出「最近可用替代」一键下单；当日散客单可核销/取消
- `/courses` 建周期班课（周几/时段/周数/顺延或补课），查看每节排期与节假日标注，整段请假/撤销
- `/members` 会员卡：总额/冻结/可用、开卡、储值卡充值、近期预订
- `/reports?ym=2026-09` 教练班课占用表、场地利用率表（开放格口径）、会员消费与违约表（含收入合计）
- `/admin` 法定节假日维护（加入即全班课按各自配置重排）、爽约扫表

## 验收五步（对应 acceptance.test.ts）

1. **建周期班课看批量占场**：周二 19:00–21:00 一号羽毛球场、12 周 → 12 节场次全部落库并占场
2. **同时段下散客单看拦截+替代**：9/22 19:00 撞班课被拦，提示冲突班课，并首选同日同时段三/四号场
3. **储值卡预订看冻结再核销扣减**：19:00–20:00 冻 34.00（场租 30 + 灯光 4），余额不变；核销后扣 34.00，收入落账
4. **开始后 30 分钟不核销看爽约**：10:30 扫表 → 扣 2 次、单置 no_show、记违约 1 次
5. **节假日叠进班课周**：9/25 中秋加入后，顺延班第二节挪到 9/26（orig_date=9/25），
   补课班 9/25 置 leave 并在周期结束后的周五 10/30（种子里 8 周班为 11/13）补一节

种子中 `青少年篮球班`（周四，10/1 国庆）演示顺延到 10/2；
`少儿羽毛球启蒙班`（周五，9/25 中秋，补课策略）演示 leave + 11/13 补课。
